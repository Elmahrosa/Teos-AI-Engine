## What Is TEOS AI Engine?

TEOS is a **content operating system** — not just an AI writer.

Every post gets a **TEOS Signal Score™ (0–100)** that predicts reach and engagement _before_ you publish. You don't guess. You know.

```
Your idea
    ↓
TEOS generates platform-specific post
    ↓
Visibility Score: 92/100 · Best time: 8–10 AM
    ↓
Suggested CTA + hashtags
    ↓
One-click share to 7 platforms
```

## Features

### 🎯 7-Platform Generation
Each post is written for its platform — not copy-pasted:

| Platform | Icon | Style |
|----------|------|-------|
| X / Twitter | 𝕏 | Short, punchy, thread-ready |
| LinkedIn | in | Founder story, authority insight |
| Facebook | f | Community, conversational |
| Instagram | ◎ | Visual caption, emoji-balanced |
| TikTok | ♪ | Video hook, script angle |
| Threads | @ | Short conversation starter |
| Telegram | ✈ | Channel / community update |

### 👁 TEOS Signal Score™
Proprietary scoring across 10 signals:
- First-line hook strength
- Specificity (numbers, names, timeframes)
- Engagement trigger (question, CTA)
- Platform fit
- Hashtag quality
- Emotional hook
- Novelty
- Length optimization
- Value proposition clarity
- CTA clarity

Score range: **55–98**. Never hardcoded. Includes ±3 variance so repeated prompts produce different scores.

### 🌍 English + Arabic Bilingual Mode
Native Arabic content — **not translated English**:
- Arabic hooks: `هل تعرف لماذا...` / `رأي غير شائع:` / `ما لا يخبرك به أحد عن...`
- RTL formatting in generator output
- Arabic hashtag pools: `#ريادة_الأعمال` `#مؤسسون` `#ذكاء_اصطناعي`
- MENA founder tone and positioning
- Localized posting times (GST / EGT)

### 10 Tone Modes
Professional · Engagement · Authority · Founder Story · Launch · Contrarian · Community · Viral Hook · Educational · Sales CTA

### 🎨 Image Prompt Engine
Platform-specific AI image prompts ready for Midjourney or DALL-E:
- X post card (1200×675)
- LinkedIn cover (1128×191)
- Instagram square (1080×1080)
- TikTok thumbnail (1080×1920)
- Facebook visual (1200×630)

### 🎬 TikTok Video Script
For TikTok platform, returns full video script:
- Hook (0–3 sec)
- 3 scene beats
- Caption
- CTA

### ⚡ Instant Distribution
Share directly from the generator — intent URLs for X, LinkedIn, Facebook, Telegram, WhatsApp, Threads. Copy-to-clipboard for Instagram and TikTok.

## Self-Deploy

> **Note:** Auth, payments, and database are pre-configured for the hosted version. Self-deploying requires your own API keys.

```bash
git clone https://github.com/Elmahrosa/Teos-AI-Engine
cd Teos-AI-Engine
npm install
cp .env.example .env.local
# Fill in your keys (see below)
npm run dev
```

### Required Environment Variables

```bash
# AI
ANTHROPIC_API_KEY=sk-ant-...

# Database (Neon PostgreSQL)
DATABASE_URL=postgresql://...
DIRECT_URL=postgresql://...

# Auth
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-here

# Payments
DODO_API_KEY=...
DODO_WEBHOOK_SECRET=...

# Vercel KV (real-time seat counter)
KV_REST_API_URL=https://...
KV_REST_API_TOKEN=...

# Internal
INTERNAL_KEY=your-internal-secret
NEXT_PUBLIC_APP_URL=https://teos-ai-engine.vercel.app
```

## Architecture

```
app/
├── page.tsx                    Landing page
├── dashboard/                  Generator dashboard
├── (auth)/                     Auth flows (login, signup)
├── pay/pi/                     Pi Network checkout
└── api/
    ├── generate/route.ts       AI generation endpoint
    ├── seats/route.ts          Real-time KV seat counter
    └── webhooks/dodo/          Payment webhook (increments seats)

components/
├── PostGenerator.tsx           Main generator (bilingual)
├── StickyCTA.tsx               Mobile sticky conversion bar
├── ExitPopup.tsx               Exit intent offer
├── useSeats.ts                 Live seat counter hook
└── landing/                    Landing page sections

lib/
├── ai/platforms.ts             Platform configs + scoring
├── arabic-prompts.ts           Arabic content system
├── auth.ts                     NextAuth config
└── limits.ts                   Usage limits by plan
```
